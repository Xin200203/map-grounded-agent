## 一句话版本

机器人拿到一句话目标（比如"黑色的电视机，旁边有沙发"），在一个**从没见过的房子**里，每走一步就：**看一眼 → 更新地图和"见过的东西清单" → 判断有没有值得改主意的新情况 → （必要时）选一个新的语义方向 → 把方向翻译成地图上一个具体的点 → 朝那个点走**。走到目标 1 米内停下就算成功，1000 步内没做到就算失败。

## 五个角色的分工（比喻版）

| 角色 | 代码位置 | 干什么（比喻） |
|---|---|---|
| **眼睛** | Mask-RCNN / GroundedSAM 检测器 | 每帧把看到的东西框出来（"这是椅子""这是电视"） |
| **制图员** | `BEV_Map` | 把深度信息拍平成一张俯视地图：哪里是墙、哪里走过、哪里没探索 |
| **记账员** | `Graph`（场景图） | 维护"见过的东西清单"：每个物体一个节点（名字+坐标+见过几次） |
| **指挥官** | `HighLevelPlanner`（LLM）+ 控制器 | 决定"现在该去哪找"：选一个物体/房间/方向 |
| **司机** | UniGoal FMM 执行器 | 拿到地图上一个点，负责具体怎么绕开障碍走过去 |

关键设计原则（论文里叫 graded semantic authority）：**LLM 只能"建议"，不能"驾驶"**——它的每个输出都要经过证据检查和地图检查才能变成行动。

## 完整链条 S0–S9（每步都有 trace 可查）

- **S0 观测**：拿到 RGB-D 图像，检测器framing出物体。
- **S1 进图**：检测结果经过一道"门"（聚类点数、检测次数等）才能成为场景图节点。*门太严=东西进不了清单（曾经的最大卡点）；门太松=坐标不准（后来发现的代价）。*
- **S2 候选识别**：新节点的名字和目标描述做匹配（如 caption "tv" vs 目标"黑色电视"→ 满分）。匹配≥0.75 就喊一声"发现疑似目标！"。
- **S3 事件触发**：疑似目标出现/进了新房间/走到了探索边界/卡住了——这些事件会触发"重新想想"。
- **S4 菜单**：把当前可选项整理成菜单给 LLM：`[object] tv`、`[room] bedroom`、`[direction] north`。只列"真的能翻译成坐标"的选项。
- **S5 选择/承诺**：LLM 从菜单选一个 → 变成策略。选了目标物体就形成**承诺**（commitment）。*C4 补丁：满分候选出现时直接确定性承诺，不再赌 LLM 会不会选它。*
- **S6 落地**：把语义策略翻译成地图坐标——目标近且可信 → 直奔；目标远 → 变成"搜索锚点"，用"目标进度分"给每个探索边界打分（哪个 frontier 更接近目标方向）。
- **S7 承诺维持**：走的过程中卡住了/原地打转，老逻辑会"换个目标算了"；*C2 补丁：只换路线，不换目标（路径失败≠目标错了），配安全阀。*
- **S8 接近与判停**：走到目标附近，执行器要"亲眼看见"目标、锁定、贴近到 1 米内、停下。
- **S9 判定**：停下位置离真目标 <1 米 → 成功。

## 控制质量机制一览（消融实验的对象）

| 机制 | 作用 | 实验结论（一句话） |
|---|---|---|
| 事件驱动调度 | 有新情况才重规划（vs 固定每40步） | 消灭无效目标震荡的主力之一 |
| 恢复机制（出窗/卡死） | 目标点跑出局部窗口→移窗重投影 | 出窗退化 43→3（14×） |
| LLM monitor | 用小模型盯着"策略是否过期" | **零贡献**（两通道验证） |
| prefetch | 提前预取下一个策略 | 无收益且多花一倍 planner 调用 |
| 语义门控×4 | 相关性门/直执门/进度项/停滞退委 | 单个可拆（下层兜底），合体贡献效率 |
| C2 承诺粘性 | 路径失败不弃目标 | 病灶集内 100% 翻转（159/358） |
| C4 自动承诺 | 满分候选直接建锚 | 在体验证生效（527 次触发） |
| C5 锚级分层 | 坐标只信"见过≥2次"的节点 | 防幻影锚点 |

## 三个实验条件（"regime"）

1. **弱语义**：planner 用 deepseek-chat（便宜、纯文本）——主战场。
2. **强语义**：planner 用 Claude Sonnet 4.5——验证结论是否依赖 LLM 强度。
3. **召回修复**：把 S1 的门放宽一行参数（物体见 1 次就进清单）——世界模型从平均 6 个物体变成 16 个。

所有对比都在**同一批 48 个 episode（12 个陌生场景）上配对进行**，这是全部结论的统计基础。
